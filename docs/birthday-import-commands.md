# 生日数据导入命令

以下命令适用于本仓库的独立生日插件。生日数据来自
[bot_tools 的生日表 CSV](https://github.com/AhsokaTano26/bot_tools/blob/main/Goods%20-%20%E8%A7%92%E8%89%B2%E5%90%8D%E5%8D%95%20%28%E7%94%9F%E6%97%A5%E8%A1%A8%29%202026-05-27_11-53.csv)，
按姓名去重后共 **118 位：61 位角色、57 位声优**。

逐人生日核查和来源见 [生日数据网络核查](birthday-data-audit.md)（2026-10-11）。

先按 [生日插件说明](birthday.md#启用) 完成数据库迁移并重启机器人。
导入生日、创建标签和关联标签需要 `SUPERUSERS` 权限。
在 QQ 群内按当前机器人的使用方式 @ 机器人，**每条命令单独发送**；
复制代码块时不需要复制 Markdown 标记。

## 一条命令导入全部预设

如果直接使用完整预设，只需发送：

```text
生日 导入预设
```

这会导入生日并建立 `BanG Dream`、`角色`、`声优` 三个标签及其关联。
重复执行不会覆盖已有成员的生日，会补齐预设标签关联。
使用此方式后，可以直接跳到“设置群名并订阅”。

## 补齐标签关联

分批导入完成后，发送以下命令，自动补齐预设标签关联；已经导入的生日会保留：

```text
生日 导入预设
```

| 当前插件标签 | 关联范围 | 人数 |
| --- | --- | --- |
| `BanG Dream` | 全部角色和声优 | 118 |
| `角色` | 角色 | 61 |
| `声优` | 声优 | 57 |

参考仓库的 [旧数据库](https://github.com/AhsokaTano26/bot_tools/blob/main/data/db.sqlite3)
只有 `BanG_Dream!` 一个标签，97 位成员全部关联该标签，没有按乐队划分的标签。
这里使用 CSV 中的 118 位成员，并由当前插件建立上表的三个标签；
旧数据库与 CSV 的名单并不完全一致。订阅全部预设时，请使用当前标签名 `"BanG Dream"`。
当前插件没有 `批量关联` 命令，使用 `生日 导入预设` 完成预设关联。

## 设置群名并订阅

在需要接收提醒的群内发送以下命令，将 `你的原群名` 替换为生日结束后需要恢复的群名称：

```text
生日 群名 你的原群名
```

订阅全部角色和声优。标签名中含空格，英文双引号需要保留：

```text
生日 订阅 "BanG Dream" 1
```

如果只想订阅角色或声优，可用下列命令之一代替上面的全部订阅：

```text
生日 订阅 角色 1
```

```text
生日 订阅 声优 1
```

订阅多个标签时取成员并集，同一个成员不会重复出现。
如果已经订阅了全部标签，想改成只订阅角色或声优，先退订全部标签：

```text
生日 退订 "BanG Dream"
```

末尾的 `1` 是建议群昵称格式，也可以改为 `2` 或 `3`：

| 格式 | 建议群昵称示例 |
| --- | --- |
| 1 | `我的群🎉@名字生日快乐🎉` |
| 2 | `我的群(@名字生日快乐!)` |
| 3 | `我的群(@名字生日快乐🎂)` |

查看本群设置和明天的建议：

```text
生日 状态
```

```text
生日 预览
```

插件每天北京时间 **23:00** 检查明天的生日，在建议群昵称发生变化时发送提醒及完整新昵称。
需要手动修改群名称；生日结束后的下一次检查会在需要时提醒恢复原名。

## 查询与自定义关联

查看标签和指定月份的生日。下例查询 1 月，可将 `1` 改为 `1–12` 中的其他月份：

```text
生日 标签
```

```text
生日 成员 1
```

如需自己的分组，可以逐条创建标签、关联成员并订阅。下面示例仅关联千早爱音和高松灯：

```text
生日 增加标签 自定义
```

```text
生日 关联标签 千早爱音 自定义
```

```text
生日 关联标签 高松灯 自定义
```

```text
生日 订阅 自定义 1
```

要让本群仅使用这个分组，应退订已订阅的其他标签。完整管理命令见 [生日插件说明](birthday.md#命令)。
