# RSS 使用指南

[返回项目首页](../README.md) · [部署说明](deployment.md)

机器人通过 RSSHub 获取动态并定时推送。订阅对象需要先加入可访问用户列表，由超管管理；群内所有成员可订阅、退订和修改本群推送配置。

## 配置平台与用户

首次部署并完成数据库迁移后，用 SQLite 工具在 `data/db.sqlite3` 的 `Plantform` 表中添加平台：

| 字段 | 内容 |
| --- | --- |
| `name` | 平台名，添加用户时使用同一名称 |
| `url` | RSSHub 路由前缀，末尾接用户 ID；从 [RSSHub 路由文档](https://docs.rsshub.app/) 查找 |
| `need_trans` | 是否需要翻译，`1` 为需要，`0` 为不需要 |

请求地址由 `RSSHUB_HOST + url + 用户ID` 拼接。下面是 SQL 模板，执行前替换平台名与路由前缀：

```sql
INSERT INTO Plantform (name, url, need_trans)
VALUES ('平台名', '/路由前缀/', '1');
```

超管在群内添加用户：

```text
增加用户 <用户ID> <用户名> <平台名>
```

`用户ID` 是对应平台用于 RSSHub 路由的标识，例如账号 handle 或 UID；`用户名` 是展示名称。名称含空格时使用英文双引号。

## 群内命令

在群内 @ 机器人使用。`<参数>` 表示必填，`[参数]` 表示可选，不输入尖括号或方括号。

| 命令 | 用途 |
| --- | --- |
| `帮助` | 打开指令与按钮面板 |
| `用户列表` | 查看可订阅用户 |
| `rss <用户ID> [序号]` | 查看文章；序号默认 `0`，即最新文章 |
| `文章列表 <用户ID>` | 查看文章序号与标题 |
| `订阅` / `订阅面板 [页码]` | 打开订阅选择面板 |
| `订阅 <用户ID> [用户ID…]` | 订阅一个或多个用户 |
| `取消订阅` / `退订面板 [页码]` | 打开退订选择面板 |
| `取消订阅 <用户ID> [用户ID…]` | 退订一个或多个用户 |
| `查询 群组` | 查看本群订阅 |
| `群组配置 <转发> <自我转发> <翻译> <图片提示>` | 设置本群推送选项 |
| `查看配置` | 查看本群设置 |

订阅与退订自动使用当前群 OpenID，无需在命令中填写群号或群 OpenID。多个用户 ID 用空格分隔。

### 群组配置

四项参数均为 `1`（开）或 `0`（关），按以下顺序填写：

1. 转发：是否推送博主转发他人的动态。
2. 自我转发：是否推送博主转发自己的动态。
3. 翻译：是否附带中文翻译，还需平台启用 `need_trans` 并配置翻译服务。
4. 图片提示：发送图片前是否提示图片数量。

推荐设置，也是无参数执行 `群组配置` 时写入的值：

```text
群组配置 1 0 1 1
```

## 超管命令

在 `.env.prod` 或 `.env.dev` 的 `SUPERUSERS` 中配置成员 OpenID 后使用。

| 命令 | 用途 |
| --- | --- |
| `增加用户 <用户ID> <用户名> <平台名>` | 将用户加入可访问列表 |
| `删除用户 <用户ID>` | 从可访问列表删除用户 |
| `订阅列表` | 查看全部群的订阅 |
| `查询 群组 <群OpenID>` | 查看指定群订阅 |
| `查询 用户 <用户ID>` | 查看用户被哪些群订阅 |
| `订阅统计` / `发送统计` | 查看订阅与发送统计 |
| `refresh` | 手动触发刷新 |
| `/发送 <内容>` | 向订阅群广播通知 |
| `/信号` / `/信号否` | 查看推送开关 / 启用推送 |
| `清理失效订阅` | 查看由官方群事件维护的订阅状态 |

机器人被移出群时会通过官方事件自动清理该群订阅和配置。

## 导入 X 关注

在与机器人的**私聊**中发送：

```text
导入关注 <群OpenID> <auth_token> <ct0> <X用户名>
```

从已登录 X 的浏览器开发者工具中，在 Application → Cookies 找到自己的 `auth_token` 和 `ct0`。机器人将关注列表与可访问用户匹配，再按返回的提示到目标群确认批量订阅。
