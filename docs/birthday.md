# 生日提醒插件

独立插件位于 `nsy/plugins/birthday`，随现有 `plugin_dirs` 自动加载。它参考
[bot_tools 的 group_title 插件](https://github.com/AhsokaTano26/bot_tools/tree/main/src/plugins/group_title)，
使用当前 QQ 官方适配器发送提醒。与参考插件一致，这里的“群昵称”指群名称。

每天北京时间 **23:00** 检查明天的生日，只在建议群昵称发生变化时向该群发送
提醒，包含日期、生日成员、可复制的完整新昵称。生日结束后，下一次 23:00
检查会提醒恢复原名；普通日子不会反复发送恢复提醒。

## 启用

更新代码或镜像后，在正常部署环境执行 `nb orm upgrade`，应用生日插件的独立
迁移分支。迁移只新增五张 `birthday_*` 表，不导入旧 QQ 群号或修改 RSS 表。
Docker 可在运行中的容器内执行 `docker compose exec nonebot nb orm upgrade`。
重启机器人加载插件；开启 `ALEMBIC_STARTUP_CHECK` 时，应在重启前完成迁移。

`BIRTHDAY_REMINDER_ENABLED=true` 为默认值；设置为 `false` 并重启可全局停用
定时提醒，查询和数据管理命令仍可使用。未设置原群名、未订阅标签的群不会
收到生日提醒。无需添加新的依赖或填写目标群配置，群 OpenID 从当前会话取得。

首次使用：

1. 超管发送 `生日 导入预设`，导入参考仓库的角色和声优生日。
2. 在目标群发送 `生日 群名 我的群昵称`，保存需要恢复的原名。
3. 发送 `生日 订阅 "BanG Dream" 1`，订阅全部预设生日。
4. 发送 `生日 预览`，查看明天的建议。预览不会修改定时提醒状态。

预设标签包括 `BanG Dream`（全部）、`角色`、`声优`。每个名字独立存储，
同一天的多位成员会用 `&` 合并到建议昵称中。重复导入预设不会覆盖手动修改
过的生日。出生年份没有参与提醒；日期为公历 `MM-DD`，闰日只在闰年触发。

## 命令

所有命令使用独立的 `生日` 前缀，遵循现有 `COMMAND_START` 配置。在 QQ 群内
按当前机器人的消息接收方式 @ 机器人使用，例如 `@机器人 生日 帮助`。
`生日帮助` 也可打开帮助。

本群设置与现有 RSS 订阅采用一致权限：群内所有成员可操作本群；全局生日表、
标签的写入和全群订阅查询仅允许配置在 `SUPERUSERS` 中的成员 OpenID。
官方群成员角色并非此插件的权限依据。

| 命令 | 用途 |
| --- | --- |
| `生日 帮助` | 查看完整用法 |
| `生日 群名 <原群昵称>` | 设置或更新原名，不会修改 QQ 群资料 |
| `生日 订阅 <标签> <格式1-3>` | 订阅本群生日；格式是本群统一格式 |
| `生日 退订 <标签>` | 退订；最后一个标签退订后仍保留一次必要的恢复提醒 |
| `生日 状态` | 查看本群原名、标签、格式、上次成功发送的建议 |
| `生日 预览` | 查看明天建议，不发送主动提醒、不修改状态 |
| `生日 成员 [月份1-12]` | 查询生日与标签，数据多时按月份查看 |
| `生日 标签` | 查看可订阅标签 |
| `生日 导入预设` | 超管导入附带生日数据 |
| `生日 增加成员 <名字> <MM-DD> [备注]` | 超管新增生日 |
| `生日 修改成员 <名字> <新名字或MM-DD>` | 超管修改名字或生日，保留标签 |
| `生日 删除成员 <名字>` | 超管删除成员及其标签关联 |
| `生日 批量导入 名字1 MM-DD, 名字2 MM-DD` | 超管批量新增或更新生日；也支持中文逗号、换行 |
| `生日 增加标签 <标签>` / `生日 删除标签 <标签>` | 超管管理标签 |
| `生日 关联标签 <名字> <标签>` / `生日 取消关联 <名字> <标签>` | 超管管理成员归属 |
| `生日 查看订阅` | 超管查询全群生日订阅 |

名称包含空格时使用英文双引号，例如 `生日 增加成员 "示例 成员" 02-29`。
原群名允许 1–40 个字符，按参考插件将最终建议控制在 60 个字符以内；生日名单
过长时，在昵称中缩短为“等 N 人”。提醒优先保留完整昵称，正文名单过长时按
现有 QQ 消息长度限制截断，完整生日表可通过 `生日 成员 <月份>` 查询。

三种格式与参考插件相同：

1. `我的群🎉@名字生日快乐🎉`
2. `我的群(@名字生日快乐!)`
3. `我的群(@名字生日快乐🎂)`

## 提醒状态

插件记录的是**已成功发送的建议昵称**。它无法读取用户是否已手动完成改名，
不会宣称群名称已经被修改。只有建议与上次不同才提醒；发送失败不更新状态，
其他群继续处理，下次定时检查按届时“明天”的生日重算，不补发过时生日。
数据库写入失败时可能重复提醒，具体错误会写入日志。

状态保存在现有数据库中，重启不会重复发送相同建议。机器人被移出群时，通过
`GROUP_DEL_ROBOT` 事件清理本插件的群配置和订阅。定时任务的错过执行容忍为
60 秒，离线更久时会等下一个 23:00，不在重连后突然发送昨天的建议。

预设 CSV 来自参考仓库的 `Goods - 角色名单 (生日表) 2026-05-27_11-53.csv`，
源许可保留在 `nsy/plugins/birthday/data/LICENSE`。此数据可通过管理命令维护，
不会自动与参考仓库同步。

验证命令：`python -m unittest discover -s tests`。
